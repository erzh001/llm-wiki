# decisions/ — датированные прецеденты

Принятые архитектурные и процессные решения неймспейса: вердикт + почему +
контекст + статус. Включая **негативные** решения («отказались от X — вот
почему») — они избавляют следующую сессию от повторного спора.

## Конвенции

- Имя файла: `YYYY-MM-DD-<slug>.md` (идентичность = дата решения).
- Frontmatter: `type: decision`, `status: accepted | active | superseded`,
  `date`, `tags`, `related`.
- Вытесненное решение остаётся (история) с указателем на то, что его заменило.
- Путь созревания: [[meta-vault/ideas/README|ideas/]] → сюда.
