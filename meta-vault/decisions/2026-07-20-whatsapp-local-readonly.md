# WhatsApp: локальное read-only чтение

## Контекст

Владельцу нужен доступ агента к личной переписке WhatsApp — **только чтение**,
безопасно, на своей машине. У личного WhatsApp нет официального read-only API:
всё, что читает личные чаты, работает либо через привязку устройства (linked
device / QR), либо через локальные данные приложения.

Обнаружено: нативное приложение WhatsApp (App Store) хранит **всю историю
локально в незашифрованной** базе Core Data:
`~/Library/Group Containers/group.net.whatsapp.WhatsApp.shared/ChatStorage.sqlite`
(текст в открытом виде, ~24k сообщений, ~900 чатов на момент решения).

## Вердикт

Читаем **локальную `ChatStorage.sqlite`** в read-only через **снапшот-копию**,
обычным `sqlite3`. Метод и рецепты — [[meta-vault/tech/whatsapp/README|tech-профиль]],
исполняемый помощник — `meta-vault/tech/whatsapp/wa-read.sh`.

## Отвергнутые альтернативы (негативные решения)

- **QR-мост / неофициальная библиотека** (whatsapp-mcp, Baileys, whatsapp-web.js):
  привязывает устройство к аккаунту, технически против ToS WhatsApp → ненулевой
  риск бана номера. Отклонено — локальная БД даёт то же чтение с **нулевым**
  риском бана.
- **WhatsApp Cloud / Business API**: только для бизнес-номеров, к личным чатам
  доступа не даёт. Неприменимо.
- **WhatsApp Web под управлением браузера**: годится для разового «посмотреть»,
  но это не источник с локальной историей (нет базы, нельзя индексировать).
  Оставлено как запасной ручной путь, не как коннектор.

## Инварианты (обязательны при любом доступе)

- **Только чтение.** Пишущих операций к WhatsApp нет по построению.
- **Оригинал не трогаем.** Работаем со снапшот-копией (`ChatStorage.sqlite`
  + `-wal` + `-shm`), базу приложения открываем только на копирование.
- **Снапшот эфемерный.** Копия в `/tmp`, чистится на выходе; не коммитится,
  не индексируется.
- **Данные `private`, вне git.** Экспорт чатов → `life/inbox/whatsapp/`
  (покрыто `.gitignore` через `life/inbox/*`), `trust: derived`.

## Следствия

- Это **снимок**: новые сообщения появляются в базе только после того, как их
  получит и синхронизирует десктоп-приложение.
- Медиа лежат отдельными файлами (в базе — ссылки/метаданные), не в `ZTEXT`.
- Люди из чатов линкуются в [[meta-vault/people/README|people/]] — живой граф.
