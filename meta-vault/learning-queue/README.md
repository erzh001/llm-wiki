# learning-queue/ — личная очередь разбора владельца

Материал для изучения и расширения семантики владельца как
пользователя-человека: новые слова, концепты, разборы. Агент **кладёт** сюда
сам (заметил термин или концепт, который владельцу стоит освоить) или по его
просьбе; разбирает — владелец, выделенной сессией. Это не задачи и не идеи
системы — это обучение человека.

## Отличие от соседей

| Зона | Держит | Кто закрывает |
|---|---|---|
| **`learning-queue/`** (эта) | материал для личного разбора: объяснить, изучить, решить | владелец, отдельной сессией |
| `ideas/` | предложения мета-уровня, зреют до decisions | градация idea → decision |

## Конвенции

- Имя: `YYYY-MM-DD-<slug>.md`. Один файл = одна тема разбора.
- Frontmatter: `type: note | reference`, `status: active | done`, `related:`.
- После разбора: исход уходит в decisions / ideas / principles или
  отбрасывается; файл получает `status: done` + одну строку исхода (историю
  не удаляем).
