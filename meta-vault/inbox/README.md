# inbox/ — кидай что угодно, ничего не теряется

Единая дверь захвата мета-уровня. Ссылка на статью, видение, идея, задача,
случайная мысль — один файл `YYYY-MM-DD-<slug>.md`, ноль церемоний: frontmatter
не обязателен, достаточно одной строки. Владелец кладёт сам или говорит
«в inbox» в чате — агент записывает.

Правила:

- **Не хранилище.** Всё отсюда разбирается на регулярной сессии разбора
  бэклога: идея → `ideas/`, задача → домен-исполнитель (+ одна строка в
  [[meta-vault/backlog|backlog]]), материал для изучения владельцем →
  [[meta-vault/learning-queue/README|learning-queue/]], внешний материал
  (статья, ссылка) → в домен, которому он нужен.
- Каждый разобранный пункт оставляет **однострочный след в
  [[meta-vault/backlog|backlog]]** — это и есть гарантия «ничего не теряется».
