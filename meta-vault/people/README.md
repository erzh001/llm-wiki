# people/ — реестр людей

Одна карточка на человека, который встречается в **≥2 доменах** или важен
поперёк неймспейса. Карточка отвечает «кто это» (имя, алиасы, идентификаторы,
где его упоминания) — **не** «что он значит»: прочтения и контекст остаются
в доменах.

## Схема карточки

```yaml
type: person
relation: personal | public | historical
aliases: [все встречавшиеся написания]
ids: {…}                 # только уже всплывшие идентификаторы (мессенджер, соцсеть)
sensitivity: private     # всегда
```

Тело: 1–2 строки кто это → «Где упоминается» (указатели по доменам) →
«Заметки реестра» (открытые вопросы идентичности, что не склеивать).

## Правила

- **Карточки людей — всегда `sensitivity: private`** и в публичный remote не
  уходят (закрывается через `.gitignore` или приватный репозиторий). Сам этот
  README — `sensitivity: normal`: здесь только правила зоны, ни одного
  человека.
- Живой кросс-доменный человек → карточка тут; доменный материал — канон в
  домене, тут — идентичность и указатели.
- Разъехавшиеся написания сводятся в `aliases`.
- Имена файлов — lowercase english (`alice.md`), контент — русский.
