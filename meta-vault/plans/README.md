# plans/ — полка, не календарь

Стратегические сборки и планы-на-чтение. **Не** зона календарных обязательств:
план с WIP-лимитами и статусом «активный», у которого нет ежедневного драйва,
не переживает контакта с реальностью — поэтому обязательства на этой полке
не живут.

Обязательства ведутся иначе:

- **Захват** → [[meta-vault/inbox/README|inbox/]] (кидай что угодно, ноль церемоний).
- **Реестр** → [[meta-vault/backlog|backlog]] — все живые пункты одной строкой.
- **Ритуал** → регулярная сессия разбора бэклога.

Здесь лежат: планы-на-чтение перед диспатчем (агент пишет — владелец читает —
исполнитель получает), стратегические сборки, ретро выполненных планов
(`status: done | reference`).
