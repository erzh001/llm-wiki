# documents/ — приёмник документов

Документы (сканы, справки, договоры, PDF и т.п.), которым не нашлось домена.
Содержимое **вне git** (см. `.gitignore`) — трекается только этот README.

Правила:

- Имя файла — поисковый крючок: `YYYY-MM-DD-<что-это>.pdf` или говорящее имя.
- Документ, принадлежащий домену, живёт в домене (учебные материалы →
  `study/`), здесь — только внедоменное.
- Ничего чувствительного в git не попадает по построению; если документ нужен
  агенту — в meta-vault кладётся карточка-указатель, не сам файл.
