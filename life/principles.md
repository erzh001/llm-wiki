# Принципы life

Правила живого личного vault'а. Следуют конвенциям базы уровня
(`../meta-vault/principles.md`) с личными отличиями.

## Что сюда попадает

Только **первоисточник, которому владелец доверяет** (`trust: primary`):

- дневник, который владелец писал сам или как минимум проверил;
- его осмысления, эссе, авторские тексты.

**НЕ сюда:**

- производное ИИ (синтезы, дистилляты) — им будет своя зона `derived`, когда
  появятся; сюда только своё;
- тяжёлые файлы (аудио/видео) → `../creative/media/` и `../documents/`;
- код и рабочие материалы → рабочие домены.

## Граница доверия

`trust` — метаданное первого класса. Папка = физически прошитая граница:
здесь **бедрок**. Если страница выросла из ИИ-анализа и владелец её не
проверил — ей место не здесь.

## Форма

- Один файл = один объект; frontmatter `title / date / type / tags`.
- Дневник: имя файла `YYYY-MM-DD.md`, `type: diary`.
- Личный регистр: естественный язык, структура не навязывается.
- Никаких секретов (паролей, ключей) в файлах.
- Markdown — портативно: данные переживают любой LLM-инструмент.

## Приватность

Содержимое `diary/` и `inbox/` — в `.gitignore` (структура трекается, контент
локальный). `texts/` трекается — это банк авторских текстов; то, что не должно
уходить даже в приватный репозиторий, живёт в diary.
