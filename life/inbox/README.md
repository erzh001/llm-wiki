# inbox/ — сброс личного

Кидай что угодно личное, что ещё не разложено: мысль, заметку, ссылку.
Один файл `YYYY-MM-DD-<slug>.md`, без церемоний. Разбирается по настроению:
дневниковое → `diary/`, авторское → `texts/`.

Содержимое вне git — трекается только этот README.

## Крупные приёмники (вне git)

- `chatgpt-export-2026-07-27/` — полный экспорт ChatGPT (386 диалогов,
  2023-09 → 2026-07, +476 вложений). Внутри `INDEX.md` (раскладка по доменам),
  `README.md`, `ATTACHMENTS.md`. Первоисточник; дистиллят — в vault доменов.

## Онлайн-источники (не файл)

- **claude.ai** — история чатов/проектов владельца (онлайн, не выгружается).
  Карта + маршрутизация (трекается) — [[meta-vault/inbox/claude-ai-chats|meta-vault/inbox/claude-ai-chats]].
  Личный/чувствительный сырой контент оттуда → сюда (локально, вне git).
