# secrets/ — глобальный личный уровень

Живёт в корне неймспейса — `secrets/`. Формат — plain markdown; такое хранение
предполагает машину под единоличным контролем владельца — иначе используйте
менеджер паролей или шифрование. Три железных правила:

1. **NEVER SYNC** — не класть в iCloud/Dropbox/любой синк. Только локально.
2. **NEVER COMMIT** — корень неймспейса это git-репо: `secrets/` игнорится
   через `.gitignore`; рекомендуется дополнительно глобальный excludesfile
   (`~/.config/git/ignore` через `core.excludesfile`: `secrets/`, `*.env`,
   `*.key`, `id_*`). Не делать `git add -f`.
3. **NEVER INDEX** — если появится RAG/индексатор, `secrets/` исключается.

## Что здесь (появляется по мере надобности)

Например:

- `passwords.md` — пароли аккаунтов.
- `tokens.md` — личные API-токены вне проектов.

Проектные доступы — в `.env` соответствующего проекта, не здесь.

Карта указателей (без значений) — `../meta-vault/secrets-map.md`.
