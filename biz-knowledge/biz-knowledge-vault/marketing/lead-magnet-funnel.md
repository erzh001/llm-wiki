# Лид-магнит-воронка (SHARKS)

Детальная механика, проработанная Сардором × Нурсултаном (10.04.2025).
Операционализация англов из
[[biz-knowledge/biz-knowledge-vault/marketing/angles-and-offers|angles-and-offers]].

## Принцип — «Лестница Ханта»

Клиент проходит **стадии осознанности** (не осознаёт проблему → осознаёт →
ищет решение → выбирает → покупает). Продавать «в лоб» холодной аудитории не
работает; и «тянуть» всех по лестнице слишком долго. Нужен **вход через полезный
бесплатный инструмент**, который актуализирует проблему и даёт контакт.

## Механика воронки (пример «иммунитет»)

1. **Таргет + месседж:** «Тренировка иммунитета для детей 2–8», «Иммунитет — не
   таблетка, это система», «стимуляторов иммунитета не существует».
2. **Лид-магнит:** бесплатный **чек-лист самодиагностики иммунитета ребёнка**
   (≈9 вопросов: как спит и т.п.), разработан с **педиатром/нутрициологом**
   (Мадина, metabodies). Скачал → заполнил анкету.
3. **Захват контакта** через заполнение анкеты.
4. **Отдел продаж звонит:** по ответам чек-листа у продажника **готовое решение**
   → продаёт «специальную программу тренировки иммунитета от школы плавания
   SHARKS».

## Второй лид-магнит — «Скоро сезон»

Тот же паттерн: «Скачай инструкцию безопасности в местах, где можно плавать» →
гайд от SHARKS → контакт → звонок → продажа. Чистый полезный контент под тревогу
(безопасность на воде).

## Инструменты

Таргетолог в составе SMM (~300к/мес); обсуждали внешнего за 500к для быстрой
разработки креативов/чек-листа.

> Для edustar: паттерн «острая боль → бесплатный полезный инструмент
> (чек-лист/гайд, желательно с экспертом) → захват контакта → звонок с готовым
> решением по ответам» переносится 1:1 (напр. «диагностика уровня языка ребёнка»).
