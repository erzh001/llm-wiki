# Верхний вход в воронку — «достойный родитель» (SHARKS)

> **TL;DR.** Дистилляция `Маркетинг` (Google Doc) из Drive. Стратегия **верхнего
> входа в воронку**: привлекать не прямой рекламой бассейна, а ценностным
> контентом про родительство → доверие → мягкий мост к продукту (тур/пробное).
> Дополняет [[biz-knowledge/biz-knowledge-vault/marketing/angles-and-offers|angles-and-offers]]
> (там — боль/оффер прямого спроса; здесь — прогрев холодной аудитории). Источник —
> [[biz-knowledge/biz-knowledge-vault/sources/google-drive|Google Drive]].

## Идея

Ядро позиционирования — цель родителя **«я хочу быть достойным родителем»** (не
идеальным — вовлечённым, дающим опору). Школа = не «занять ребёнка», а среда, где
растут и ребёнок, и родитель. Сначала создаём внимание и доверие ценностными
темами, совпадающими по ЦА (родители 25–45), затем «достраиваем мост» к продукту.

## Механика воронки

1. Ценностный контент про родительство (тренды, боли, узнавание) →
2. подписка («это про моё») →
3. мета-связка: «здесь не просто про бассейн — про отношения, рост, уверенность» →
4. интерес к продукту → тур/пробное → покупка.

Каждый пост/сторис несёт **мета-связь** к философии продукта, а не прямую продажу.

## Контент-каркас (14 дней)

Чередование форматов **пост / карусель / рилс / сторис-серия**, от ценности к
мосту: ценностный манифест → вовлечение (опрос «когда гордились собой?») →
«ошибки» (5 привычек, мешающих уверенности) → история мамы → противопоставление
«кружок vs среда роста» → мнение тренера → мета-мост «как учим гордиться собой» →
**CTA: тур** (20 минут). Готовые тексты постов и сторис — в исходнике Drive.

## Приёмы

- **Сторис-серия из 5:** провокация → опрос/реакция → микроистория → вопрос
  аудитории → мягкий мост к продукту.
- **Тур как оффер** вместо «пробного»: «20 минут, которые помогут принять
  взвешенное решение», + подарок-чек-лист «7 признаков сильной детской программы».
- **Мост через систему:** уверенность ребёнка = не «характер», а результат
  системы (маршрут, поддержка без давления, честная обратная связь, микропобеды).

## Принцип (переносимо на edustar)

- **Два контура спроса:** прямой (боль → лид-магнит → оффер, см. angles-and-offers)
  и **верхний** (ценность → доверие → мост). Верхний растит тёплую базу там, где
  прямой спрос узок.
- **Продавать идентичность клиента, а не фичу** («быть достойным родителем» ≫
  «расписание занятий»).
- **Контент → мост → мягкий оффер (тур/демо)**, не прямая продажа в лоб.

> Для edustar боль иная (успеваемость, будущее, экзамены), но каркас «ценностный
> верхний вход → доверие → демо-урок» переносится 1:1.
