# Пирамида лидов и «educated choice» (Сардор)

Маркетинг-фреймворк (разработан Сардором ~2018), разобран 20.05.2025. Как
работать не с «горячими», а с «тёплыми» лидами через обучающий контент.

## Пирамида температуры лидов

Горячие (мало) < тёплые < **холодные (много)**.

- **Горячие** — знают, что хотят → конкуренция максимальная, все таргетируют,
  борьба только по **цене** (инструменты у всех одинаковы: таргет). Дорого,
  маржинально невыгодно.
- **Золото — в тёплой зоне:** тёплые ещё не приняли решение, в раздумьях; их
  **больше**, и **почти никто с ними не работает**.

## Educated choice (утепление → сделка)

Работа с тёплыми = **контент-маркетинг + этапы продаж**: **обучая клиента, делаешь
его лояльным до сделки**. Цепочка: **утепление → понимание → доверие → сделка**.
Аналогия: платная консультация (150к/час) создаёт доверие, ведущее к крупной
сделке; для широкого сегмента educated choice реализуется через соцсети,
инфлюенсеров, рекламу, полезный контент (ср. лид-магниты →
[[biz-knowledge/biz-knowledge-vault/marketing/lead-magnet-funnel|lead-magnet-funnel]]).

## Продуктовая логика продаж (down-sale)

- Продажу строят вокруг **6-месячного абонемента** (выгода финансовая +
  функциональная).
- Не готов на полгода → **down-sale**: месячный абонемент (ниже чек, напр. 45к
  вместо ~240к сделки).
- **Критическая масса ~720–740** абонементов = закрыть годовой ТБУ.
- **Конверсия из лидов:** ~20% на месячный, ~10% на полугодовой.

> Для edustar: работать с тёплой зоной через educated-choice-контент (пробные
> уроки, полезные материалы) + продавать длинный абонемент с down-sale на
> короткий — прямой перенос.
