# Источники — записи встреч, июнь (SHARKS)

Указатели, не копии. **Не разобраны** — агент напрямую видео не смотрит; путь
разбора: открыть в браузере, включить авто-субтитры YouTube (если есть),
считать транскрипт из DOM. Владелец отметил: «тут не все записи, с офлайн-встреч
не загружены».

объём), затем решить по остальным.
