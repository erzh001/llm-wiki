# Урок — эффективность собраний и вовлечённость

**Триггер:** руководитель собирает команду / проводит планёрку/воркшоп.

**Правило (от Меруерт):**
- Всегда начинать с вопроса **«какая цель этой встречи?»**. Если сам не
  понимаешь, зачем собрал — это имитация бурной деятельности: время отняли,
  решений нет = коллективная безответственность.
- **Вовлечённость персонала напрямую зависит от руководителей.** Не проводишь
  регулярно стратсессии/воркшопы/5-минутки → у команды замешательство и саботаж
  (особенно при непопулярных решениях: поднятие цен, внедрение KPI).
- Нововведения **доносить правильно**, иначе команда видит в руководителе только
  желание «нажиться».
- Каскад собраний: общие с руководителями → у менеджеров свои планёрки (видят
  план каждого, мотивируют друг друга, решают проблемы сами, напр. через
  flipchart). Инициатива снизу; руководитель работает точечно с отстающими по
  показателям.

**Почему:** без цели и ритма собрания жгут время без результата; система решает
проблемы на своём уровне, освобождая руководителя для работы с показателями.

**Кейс-провал (24.06):** команде дали задание проработать CJM/формат воркшопа —
никто ничего не сделал, «забили». Причина — нет вовлечённости и ясной цели.
