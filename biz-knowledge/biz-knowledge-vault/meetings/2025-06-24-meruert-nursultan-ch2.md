## Темы и решения

- **Job description менеджера по продажам** — Меруерт готовит из «функций» в
  Miro; затем KPI, источники данных, периодичность → отдать на ревью Нурсултану,
  потом нанимать.
- **Оплата продажников:** сейчас оклад 150 + проценты (~50/50, ±3%). Кандидат из
  Алматы: зарабатывал ~350 (250–400), хочет **400 на руки**, был график 2/2.
  **Решение-принцип: меньше фикс-оклад, больше KPI/бонус** (переменная часть).
- **Оформление:** ~80–90% неофициально; Ержан постепенно переводит на официал
  (пока ~2 менеджера официально).
- **Штат/график отдела продаж:** сейчас 2 менеджера, хотят +1 (идеал — 3 на
  смене для оборота). График 5/2; 4 дня в неделю работают по одному →
  «зашиваются», горячие лиды не отрабатываются. Ошибка: отправили 2 в отпуск
  одновременно → отдел просел (деньги, отчёты).
- **Отчёты/скрипты:** Корина не сдаёт отчёты (таргет/деньги) вовремя; новый
  скрипт внедрён, но конверсию **не отслеживают** → «не следят — не работает».
  Нужен стандарт соблюдения скриптов + контроль по показателям.

## Переносимые инструменты (промотить)

- 🧰 **Тест DISC при найме** — D/I/S/C, помогает ставить человека на своё место.
  Руководители обычно **D** (доминанты). Менеджер продаж = **D-I** (напор, не
  боится клиентов) + немного C (считать KPI) + эмпатия (не конфликтный).
  Финдиректор = C-S; медийная личность = высокий I; креативщик/СММ ≠ усидчивый.
  Бизнес-ассистент = операционщик, структурный, дисциплина, внимателен к деталям.
- 🧠 **Вовлечённость персонала = функция руководителей.** Если руководители сами
  не проводят стратсессии/воркшопы/5-минутки → замешательство и саботаж
  (особенно при поднятии цен + внедрении KPI). Нужна культура регулярных
  собраний: руководитель доносит нововведения правильно (не «нажиться»),
  у менеджеров свои планёрки (видят план каждого, мотивируют, решают проблемы
  сами через flipchart), инициатива снизу. Руководитель следит за показателями,
  точечно работает с отстающими. → урок:
  [[biz-knowledge/biz-knowledge-vault/lessons/meeting-effectiveness|meeting-effectiveness]].
