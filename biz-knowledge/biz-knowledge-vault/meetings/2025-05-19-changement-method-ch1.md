# 2025-05-19 · Встреча с руководителями — методология Changement (ч1)

**Участники:** консультант (Сардор) × руководители SHARKS. 1:47 (ч2 ~3.5ч).
Источник: `watch/T64b_-_Eric.md`. Рефлексия консультанта о своём процессе (на
примерах SHARKS и др. проектов — Агротраст/МИД).

## 3 этапа работы Changement

1. **Исследование → целеполагание → разработка стратегии** (~3–4 мес).
2. **Стратегическое согласование + тактический план** (совместно с командой).
3. **Внедрение и адаптация** — обратная связь от реальности (команда + рынок).

## Как это шло в SHARKS (переносимо)

- **Lean-итеративно** (как бережливое производство): не «4 мес исследуем», а
  «шаг → улучшение → обратная связь». Работало **быстро, потому что в управлении
  сами владельцы** (нанятая команда так не разогналась бы) + **еженедельные
  встречи** = быстрая координация/ОС.
- **Построение бизнеса = работа с барьерами** (аналогия с дисциплиной/телом):
  любой результат = преодоление барьеров + регулярность.
- **Стандартизированные процессы** нужны для спокойствия: «люди приходят/уходят —
  процесс остаётся».

## Роли в работе с компанией

- **Тактическое планирование** (встреча начала месяца: цели, KPI, ясность на месяц).
- **Tracking-сессии** (еженедельно с менеджером проекта: задачи выполнены? вовремя?
  качество/сроки/ресурсы?) → отчёт владельцу.
- **Разделение владелец / руководитель:** клиент часто «владелец-руководитель» в
  одной роли → разделяют на две (стратегия vs операционка).

> Для edustar: 3-этапный процесс + Lean-внедрение + разделение владелец/
> руководитель + tracking-сессии — методология систематизации.
