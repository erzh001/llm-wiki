# 2025-04-30 · Стратегическая сессия (ч1) — каскад цель→способ→тактика

**Участники:** консультант (Сардор) × руководители SHARKS. 4:07 (ч2 отдельно, ~5ч).
Источник: `watch/o_qXMbK6dUw.md`.

## Ключевой тезис — «снизу-вверх не работает»

Команда рвётся действовать на **уровне инструментария** (автоматизация
уведомлений, приложение для админов, скрипты, запуск абонемента) — но **действие
без тактики/плана результата не даёт**. Нужен каскад сверху вниз:

**Цель (зачем) → Способ/стратегия (как) → Тактика/план (кто · когда · за сколько)
→ Действие.** Без плана вероятность достижения ≈ 0 («как в казино»).

## Способ достижения (причинная цепочка)

Для крупной цели (напр. млрд): **поднять цены** → для этого нужен **уровень
сервиса** → чтобы клиент понимал **ценность продукта** → для этого **бренд,
которому доверяют** (обсуждают, рекомендуют). Это и есть «способ» (стратегия).

## Глобальная цель и ключевые результаты (OKR)

- **Цель: №1 школа плавания (в Павлодаре).**
- **KR:** ~**4000 клиентов** · оборот ~**960 млн ₸** · **доля рынка №1**.

## Оргмоменты

- Последний день старых цен; запуск нового прайса откладывают (не успевают).
- Автоматизация клиентских уведомлений (запись/отмена/перенос/смена тренера) —
  1-й этап сделан; собирают от блоков список уведомлений (люди забывают слать).

> «цена↑ ← сервис ← ценность ← бренд-доверие» + формат OKR (цель + 3 KR) —
