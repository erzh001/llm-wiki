# meetings/ — конспекты встреч (дистиллят видео)

Дистиллированные записи встреч SHARKS (фев–июнь 2025) из YouTube-корпуса
(пайплайн `~/Sites/sharks-video/`, см.
[[biz-knowledge/biz-knowledge-vault/sources/june-videos|sources/june-videos]]).
Один файл = одна встреча, `YYYY-MM-DD-<slug>.md`. Формат: участники · темы ·
решения · action items · переносимо на edustar.

Повторяющиеся фреймворки/уроки промотятся в тематические зоны (`sales/`,
`lessons/`, `org-design/`, `frameworks/`).

Многие встречи ведёт консультант **Меруерт** (систематизация продаж/оргдизайна;
ср. CHANGEMENT / метод Куницкого).
