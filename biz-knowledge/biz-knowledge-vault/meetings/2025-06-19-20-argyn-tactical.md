# 2025-06-19/20 · Тактические сессии Меруерт × Аргын

**Участники:** Меруерт × Аргын. 2 сессии по ~37 мин. Источники:
`watch/yleALxqfBFs.md` (19.06), `watch/Fxo9lLEe9sM.md` (20.06). Разнесение функций
цепочки создания ценности по отделам + операционный контроль.

## Разнесение функций (цепочка ценности → владелец)

- **Привлечение / маркетинг / продажи → Нурсултан** (коммерческий).
- **Адаптация клиентов / клиентский сервис (КСД) / удержание / продление /
  программа лояльности → Аргын.**
- **Предоставление услуги** (индивид/группа, адаптация программ, методконтроль,
  развитие) **→ Шамиль.**
- **Финансы / управление экономикой юнитов / контроль оплат / KPI юнитов /
  оптимизация доходности → Ержан.**
- **HR/подбор — отдельного отдела нет** (Аргын временно; Нурсултан как HR).
- **Отдел управления качеством — нет** (стандарты/регламенты/непрерывное
  улучшение/внутреннее обучение) — пробел в оргструктуре.

## Функции отдела клиентского сервиса (КСД, детально)

Ведение базы · контроль сроков абонемента · посещаемость/активность · напоминания
о продлении · организация/корректировка расписания · поддержка (телефон/мессенджер/
приложение) · сбор обратной связи по качеству · удержание/развитие (персональные
рекомендации, видео) · финансовый контроль (оплаты, задолженности).

## Проблема — контроль задолженности

**55 неоплаченных посещений** в больших бассейнах: клиенты ходили бесплатно
(абонемент кончился, но **в больших бассейнах нет админа** — только тренер +
удалённый менеджер → тренер не знает статус абонемента). → ввели **штрафы**
менеджеров. Урок: без точки контроля оплаты на юните — утечки выручки.

> Для edustar: чистое разнесение функций цепочки ценности по ролям +
> обязательная точка контроля оплаты/абонемента на каждом юните + завести отдел
> качества с самого начала.
