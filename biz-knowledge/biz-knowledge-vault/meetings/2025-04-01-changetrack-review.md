# 2025-04-01 · Воркшоп с руководителями — Change Track (отчёт)

**Участники:** консультант (Сардор) × руководители SHARKS. 1:37. Источник:
`watch/2ogFBjGl6BA.md`.

## Суть

Отчётная встреча (проверка домашних заданий цикла). **Исполнение слабое —
«времени не было»**:

- Март-отчёт не готов; **финмодель/ФОТ не пересмотрели**; ТБУ не показали;
  систему оплаты не досчитали; грейды только начали.
- **CRM-миграция → потеря данных:** перешли на новую CRM, часть данных потеряли →
  пересобирают учёт в **Google Sheets** (Нурсултан забивает продажи ежедневно,
  расходы по юнитам отдельно; цель — «справедливо, всем видно, связано с
  финмоделью»). Связь →
  [[biz-knowledge/biz-knowledge-vault/systems/crm-history|crm-history]].
- **Начали вести Notion-календарь/дневник** (даты конца марта) — это тот самый
  журнал из
  [[biz-knowledge/biz-knowledge-vault/decisions/2025-03-systematization-sprint|спринта систематизации]].
- Постпродажи (сопровождение) — сотрудников набрали, работает; хотят отделить
  продажников от сопровождения.

## Наблюдение (переносимо)

Классика внедрения: между воркшопами домашки буксуют без выделенного времени →
консультант держит **ритм отчётности** (Change Track), чтобы не терять темп.
Миграция CRM без плана = потеря данных — риск для edustar-внедрений.

> Для edustar: аргумент за встроенную аналитику/бэкап при миграции + ритм
> еженедельного трекинга задач.
