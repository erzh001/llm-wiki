# 2025-05-19 · Встреча с руководителями — картирование процессов (ч2)

**Участники:** консультант (Сардор) × руководители SHARKS. 3:31 (продолжение
[[biz-knowledge/biz-knowledge-vault/meetings/2025-05-19-changement-method-ch1|ч1]]).
Источник: `watch/XkRD8kZ1mSg.md`.

## Спагетти-диаграмма (customer journey)

Терминология операционного менеджмента — карта физического **пути клиента по
зданию** + точки контакта + тайминг:
ресепшн → гардероб → турникет → зона ожидания → раздевалка → душ → бассейн →
сауна → раздевалка → выход. Тайминг по шагам (гардероб ~5 мин, ожидание 1 мин,
раздевалка 5–7, душ 5, **бассейн 30**, …) ≈ **40 мин** с запасом. Для каждого
шага: **есть ли контакт с сотрудником компании** и кто им управляет.

## Функции администратора (детально)

Приветствие · отбить/списать абонемент · регистрация клиента · приём оплаты ·
магазин · консультация по услугам · ассистирование · координация тренеров по
графику. → администратор = **отдел клиентского сервиса**; управление юнитом =
**отдел предоставления услуг**.

## Принцип оптимизации (переносимо)

**Не перегружать роль чужими функциями.** Пример: «носить воду тренерам» съедала
внимание администратора (тренер становился ещё одним «клиентом» админа → падала
эффективность сервиса). Решение: тренер сам наполняет бутылки / отдельный человек;
администратор фокусируется на клиентском сервисе.
