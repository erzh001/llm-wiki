# 2025-03-05 · Воркшоп — финансово-экономическая модель (ФЭМ)

**Участники:** консультант × команда SHARKS. 1:52. Источник:
`watch/ZluRE78z21c.md`.

## Темы

- Проверка отработки инициатив прошлой встречи + презентация + **анализ экономики
  каждого юнита**.
- **Обучение команды ФЭМ** (финансово-экономическая модель) — инструмент
  планирования: как генерируется прибыль и расходуются средства; прогноз,
  окупаемость, решения. Применение: стратпланирование, внутренний анализ,
  привлечение инвесторов, запуск проектов.
- **Структура ФЭМ:** исходные данные/допущения → прогноз доходов/расходов →
  P&L → движение денежных средств → баланс → фин.показатели → анализ
  чувствительности.
- **Ключевые метрики (учили команду):** выручка = цена × кол-во; себестоимость =
  Σ переменных затрат; валовая прибыль = выручка − себестоимость; чистая прибыль =
  валовая − операционные − % по кредитам − налоги; рентабельность = чистая/выручка
  ×100%; **точка безубыточности** = постоянные затраты / (цена − переменные).
