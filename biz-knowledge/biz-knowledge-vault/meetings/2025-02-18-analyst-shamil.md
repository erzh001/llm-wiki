# 2025-02-18 · Бизнес-аналитик × Шамиль

**Участники:** бизнес-аналитик Changement (Аян) × **Шамиль** (совладелец,
директор спорта). 0:20. Источник: `~/Sites/sharks-video/watch/hCIKm4htDlM.md`.

## Суть

Картирование оргструктуры и процессов SHARKS через интервью собственника. Вся
фактура (точки/бассейны/штат/продукты) вынесена →
[[biz-knowledge/biz-knowledge-vault/systems/sharks-operations|systems/sharks-operations]].

## Роль Шамиля

- **Тренировочный процесс + тренеры** (26 тренеров, своя методика, стажировка
  ~1 нед, набор пловцов, корректировка) — всё через него.
- **Организация соревнований** (стартовые пакеты, медали, инвентарь из Китая,
  шоу-программа награждения).
- Партнёры «стараются не лезть друг другу в работу».

## Метод аналитика (переносимо)

Создаёт **карту процессов** «кто где что делает»: сначала интервью собственников,
затем спуск к тренерам/менеджерам (цикл дня, обработка клиента, пробное занятие),
затем выезд «в живую». → основа для новой оргструктуры и бизнес-процессов.

> Для edustar: тот же метод картирования (интервью владельцев → команда → живое
> наблюдение) при систематизации новой школы.
