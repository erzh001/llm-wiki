# frameworks/ — бизнес-фреймворки

Универсальные инструменты мышления и управления, освоенные в бизнесе
(переносимы за пределы SHARKS). Один фреймворк или подборка = один файл.

- [[biz-knowledge/biz-knowledge-vault/frameworks/business-frameworks|business-frameworks]]
  — HADI, RACI, PAM/TAM/SAM/SOM (из Notion-глоссария SHARKS).
- [[biz-knowledge/biz-knowledge-vault/frameworks/systematization-method|systematization-method]]
  — метод систематизации бизнеса, 12 модулей «Бизнес-Конструктора» Куницкого
  (пирамида систематизации, бизнес-модель-канва, центры ответственности,
  3 финотчёта, оценка 360°, стратсессии). Мета-каркас всего плейбука.
- [[biz-knowledge/biz-knowledge-vault/frameworks/strategic-management-4-aspects|strategic-management-4-aspects]]
  — 4 аспекта стратегии (бизнес/операционная/HR/маркетинговая) от консалтинга
  Changement + «стратегия = способ достижения цели» (из встречи 04.02.2025).
- [[biz-knowledge/biz-knowledge-vault/frameworks/changement-operating-cadence|changement-operating-cadence]]
  — операционный ритм Changement: типы задач (БТР), проект/операция + проектная
  доплата, 6 форматов встреч (Change Track, стратсовет, воркшопы…).
