# Фреймворк — 4 аспекта стратегического менеджмента (Changement)

Методология консалтинга Changement (стратегический менеджмент), раскрытая на
первой сессии SHARKS 04.02.2025. Мета-каркас: где в бизнесе нужно «повлиять»,
чтобы появилась определённость и управляемость. Дополняет
[[biz-knowledge/biz-knowledge-vault/frameworks/systematization-method|метод Куницкого]].

## 1. Бизнес-стратегия

- **Модель бизнеса** — как зарабатываем, как получаем прибыль.
- **Среда:** макро (страна: политика/экономика/социум/тренды), микро (отраслевая
  конкуренция, регуляторы, лицензирование) → возможности/угрозы + сильные/слабые
  стороны (SWOT).
- **Стратегическая перспектива:** миссия, видение (3–5–10 лет), краткосрочные
  цели (год).
- **Корпоративная стратегия:** портфель продуктов, стейкхолдеры, перспективность
  портфеля (пример: дети 3–5 лет — 400 тыс в городе × 10% достижимо → оборот;
  подростки — 120 тыс × 50% ёмкость). → финплан, оргструктура.
- **Итог:** контрольная карта + **стратегическая карта** (дорожная карта /
  диаграмма Ганта / **OKR** — цели и ключевые результаты).

## 2. Операционная стратегия

Бизнес-процессы для достижения цели = **цепочка создания ценности**. При
масштабе (1→3 млрд) процессы и бизнес-юниты меняются; для экспансии на города
нужна **«коробка»** — тиражируемый юнит. Без формализации внимание рассеивается,
объекты страдают, показатели падают.

## 3. HR-стратегия

Оргструктура (кто за что отвечает) + функциональная структура (за какие функции)
+ KPI, привязанные к влиянию на результат (**кто больше влияет — больше денег**).
Чёткое разделение обязанностей/результативности снимает **партнёрские
конфликты**. Иначе — все в операционке, «в корабле никого нет».

## 4. Функциональная (маркетинговая) стратегия

Сегменты (возрасты × задачи: функциональная / досуг / лечение) → ключевые
факторы успеха (для детей — **доверие родителя**) → ценностное предложение →
продуктовая линейка → платформа бренда → позиционирование → коммуникационная
стратегия/план/бюджет. Ошибка большинства — начинать «с конца» (сразу
продвижение), а не с сегментов и ценности.

## Сквозные принципы

- **Стратегия = уникальный способ достижения цели с учётом ресурсов** (≠ план =
  какие ресурсы нужны).
- **«Война инструментария»** без стратегии = телодвижение без результата
  (инструменты копируются и устаревают).
- **Стратегическая согласованность:** цели сверены между партнёрами, проверены
  на достижимость и наличие ресурсов; у каждого проекта портфеля есть исполнитель
  и стратегия.
