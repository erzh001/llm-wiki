# biz-knowledge — Бизнес-знания (дверь)

Ты в `biz-knowledge/` — домен **накопленного бизнес-знания**: дистиллированный
плейбук предпринимателя (стратегия, оргдизайн, продажи, маркетинг,
юнит-экономика, набитые шишки). Не архив одного бизнеса — **переиспользуемое
знание**, пережившее конкретный проект. Рабочий домен, соседи `edu-center/` /
`ppu/` / `chem-resale/`; создан из [[meta-vault/vault-template|vault-template]].

Имя агенту уровня не присвоено (реестр имён: [[meta-vault/glossary|glossary]]).

Читать первым (мозг — это vault):
- `biz-knowledge-vault/status.md` — текущее состояние, читать каждую сессию.
- `biz-knowledge-vault/principles.md` — конвенции (база + дельты).
- `biz-knowledge-vault/HOME.md` — карта знания.

> **Инвариант (все уровни):** НИКОГДА не использовать `AskUserQuestion` /
> попап-диалоги с выбором — вопросы владельцу всегда обычным текстом.

## Источник и назначение

- **Источник — SHARKS** (сеть школ детского плавания, «старый» бизнес
  владельца): 4 доски Miro (стратегия, оргструктура, workspace, owners space) +
  записи встреч (июнь). Raw-материал — вне git, указателями в
  [[biz-knowledge/biz-knowledge-vault/sources/README|sources/]].
- **Назначение — адаптация под edustar** (продукт `edu-center`, EduCenter
  CRM+ERP для языковых школ). Домен дистиллирует знание SHARKS в
  business-agnostic форму, из которой edustar (и будущие проекты) черпают. **Это
  единственный домен, которому разрешена кросс-ссылка в `edu-center/`** — она
  и есть его цель.

## Стадия

**Скелет vault + первичное наполнение с досок.** Стратегия/оргдизайн/маркетинг
внесены с бордов; workspace-дамп и видео — не разобраны (см. `status.md`).

## Внутри

- `biz-knowledge-vault/` — база знаний (см. HOME). Ключевые зоны: `strategy/`,
  `org-design/`, `sales/`, `marketing/`, `unit-economics/`, `lessons/`,
  `sources/`.
- Доступы (если появятся — CRM, рекламные кабинеты) — только указателями в
  [[biz-knowledge/biz-knowledge-vault/secrets-map|secrets-map]].
