# LLM-wiki — шаблон личного неймспейса

Публичный шаблон личного неймспейса для жизни с ИИ-агентами. Знание живёт как
читаемый markdown в одной папке; агент (Claude Code, Codex, любой следующий
инструмент) работает поверх. Главный принцип — **LLM-независимость**: движок и
клиент сменные и выкидываемые, данные вечные.

Для кого: для человека, который хочет вести собственную базу — дневник, домены
работы и интересов, решения, реестры — так, чтобы её одинаково понимали и он
сам (через Obsidian или любой редактор), и агент (через двери `CLAUDE.md`).

## Как начать

1. Клонировать репозиторий.
2. Открыть папку целиком в Obsidian (корень = vault Обсидиана).
3. Прочитать `CLAUDE.md` (дверь неймспейса) → `meta-vault/HOME.md` (карта знания).
4. Переименовать домены-примеры (`study`, `creative`) под свою жизнь; новые
   домены рождать из `meta-vault/vault-template.md`.

## Структура

- `CLAUDE.md` — дверь-карта неймспейса; агент подхватывает её автоматически.
- `meta-vault/` — мета-уровень: метод, глоссарий, решения, реестры, схема.
- `life/` — личный первоисточник: дневник, тексты (содержимое — вне git).
- `study/` — домен-пример: учёба.
- `creative/` — домен-пример: творчество.
- `public/` — проекция наружу: готовые внешние артефакты.
- `documents/` — приёмник файлов-документов (вне git).
- `secrets/` — доступы (вне git, никогда не коммитится).

Тяжёлые файлы, личный дневник и секреты в git не попадают по построению —
см. `.gitignore`.
