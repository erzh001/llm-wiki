# media/ — файлы работ

Аудио, видео, графика, рабочие проекты. Содержимое **вне git** (корневой
`.gitignore`) — трекается только этот README.

## Правила

- Имя файла/папки — search-hook: `YYYY-MM-DD-<что-это>` (дата = создание/событие).
- Подпапки — примеры: `drafts/` (черновики), `sources/` (исходники),
  `releases/` (опубликованное). **Рождаются от факта** при первой
  инвентаризации, не выдумываются заранее.
- Каждой значимой единице — карточка-указатель в `../creative-vault/`: файл
  без карточки = потерянный файл (агент его не видит).
- Бэкап тяжёлых файлов — отдельная забота (git их не хранит).
