# Документ-решение: рост продаж casual.kz

Свод разбора (июль 2026): диагноз → уроки modnoplus → активы → пошаговый путь с
воротами решений. Детали фактов — [[deeda/deeda-vault/overview|overview]] +
[[deeda/deeda-vault/market/modnoplus|modnoplus]]. Сценарий первого эфира —
[[deeda/deeda-vault/plans/tiktok-live-test|tiktok-live-test]].

## TL;DR

Проблема casual.kz — **не маржа и не спрос, а оборачиваемость.** 70 млн ₸
заморожены в стоке, крутятся раз в ~2 года; сезонка часто остаётся непроданной.
Секрет «диких продаж» modnoplus — тоже оборачиваемость (не реклама, не наценка).
Рычаг — **прокрутить casual/пуховики быстрее через live**, начиная с безрисковой
распродажи сезонных остатков. Двигаться по этапам, каждый финансирует следующий.

## Диагноз (на цифрах владельца)

- Выручка **8–12 млн ₸/мес** (~120 млн/год). Сток **70 млн ₸** себестоимости.
  Наценка **1к3–1к4** (~3.5×).
- Вал. прибыль ~86 млн/год (маржа ~71%) — **сильная**.
- Оборачиваемость ~**0.49/год (≈2 года)**; **GMROI ~1.2** (норма 2.5–3+) —
  **слабо**, виновата только скорость.
- Вердикт: **маржинально богат, капитально неэффективен.** Сезонные остатки =
  мёртвый капитал.

## Что взять у modnoplus (и что НЕ брать)

- **Урок:** оборот × маржа решает, не маржа. Её капитал ~6–7× продуктивнее при
  вдвое меньшей наценке — за счёт скорости (live-эфиры).
- **Механика:** TikTok LIVE 24/7 (8 местных ведущих), закуп Гуанжоу (15–20
  вагонов/мес), Казпочта, аккаунт-регион РФ (рынок = Россия), эфиры 16:00–ночь
  (пояса РФ), органика (реклама=0), CRM под фулфилмент.
- **НЕ брать:** её абсолютные числа (10–30 млн/день стоят на рынке РФ + женском
  импульсе — не твои). Её игра ≠ твой костюмный бизнес. Копируем **модель**
  (live как ускоритель оборота), не товар/рынок.

## Твои активы (чего у неё нет)

1. **Свой бренд + производство** (пуховики Китай, костюмы Узбекистан по своим
   лекалам, трикотаж Турция) — защищённость и маржа против её дженерика.
2. **Своя разработка CRM/ERP** ([[ppu/ppu-vault/HOME|ppu-crm]],
   [[edu-center/edu-center-vault/HOME|edu-center]]) — автоматизацию заказов
   строишь сам, а не платишь ~10 млн подрядчику.
3. **Живая офлайн-точка** (ТД City Centre) — трафик, которого у неё (онлайн-онли)
   нет.
4. **Канал в Китае** уже есть (производство + [[chem-resale/chem-resale-vault/HOME|chem-resale]]).

## Две модели по линиям товара

- **Костюмы** (свой бренд, отшив, высокая маржа, медленно) → традиционная
  розница: шоурум + консультация + контент. **НЕ live.**
- **Пуховики / трикотаж / casual** (сезон, импульс, свой бренд) → **live-commerce.**
  Пуховик = лучший live-клин (сезонная срочность, нужен всем, крупный визуал,
  прощает размер, свой бренд = маржа + отличие).

## Пошаговый путь (ворота решений)

### Этап 0 — Live-распродажа сезонных остатков  ← старт, риск ≈ 0
Товар и так почти мёртвый → терять нечего. Обучиться формату, расморозить кэш.
- Как: [[deeda/deeda-vault/plans/tiktok-live-test|tiktok-live-test]] (телефон,
  свет, ведущий, «БЕРУ», Google-таблица руками).
- Товар: что залежалось / остаётся к концу сезона.
- Бренд: отдельный хэндл/«сезонный сток», не мешать с премиум-восприятием.
- **Ворота:** растут ли зрители/«БЕРУ»/выручка от эфира к эфиру за 5–7 заходов?

### Этап 1 — Live на свежие пуховики к сезону  (если Этап 0 пошёл)
Свой бренд, импульс, маржа. Регулярные эфиры под пояс покупателя (KZ-вечер).
- **Ворота:** держится ли оборот выше 0.49/год на этой линии? Считать GMROI.

### Этап 2 — Масштаб  (если Этап 1 подтвердил экономику)
- **CRM/автоматизация заказов своими силами** (захват «БЕРУ» — самый хитрый кусок,
  нет API TikTok; остальное — обычная CRM).
- **Регион РФ** (аккаунт на Россию) — выход на большой рынок, эфиры 16:00–ночь.
- **Закуп под доказанный оборот** (вагоны догоняют продажи, не наоборот).

## Чего НЕ делать (ловушки)

- НЕ платить за «магический сетап/настройку TikTok» до Этапа 0.
- НЕ закупать объём в надежде на спрос до доказанной скорости эфиров.
- НЕ гнаться за абсолютной цифрой modnoplus (другой рынок/товар).
- НЕ резать цену на всё вслепую — режем на остатках, полный прайс держим отдельно.
- НЕ смешивать распродажу и премиум-бренд в одной витрине.

## Открытые вопросы (уточнить для точности)

- 250–350 тыс/день — вся выручка или только casual?
- Из 70 млн — сколько костюмы (медленно) vs casual/пуховики (быстрее)?
- Закупочная цена ходовой casual/пуховика — для точного порога окупаемости.
- Как modnoplus держит РФ-регион физически из KZ (разведка у знакомого).
