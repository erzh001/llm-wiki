# Принципы — deeda (дельты)

Следует **базе**: [[meta-vault/principles|meta-vault/principles]] +
[[meta-vault/vault-template|meta-vault/vault-template]]. Здесь — только дельты.

## Дельты

- **Клиентский розничный бизнес.** `clients/`, `market/`, `positioning.md` —
  активные зоны (портрет покупателя, канал, оффер), не заглушки.
- **`market/` = реальный рынок ритейла мужской одежды**, не продуктовый
  ландшафт. `competitors/` — другие магазины костюмов / мужской одежды в том же
  канале и гео.
- **Ассортимент — ядро.** Костюмы как якорь + сопутствующее; знание о товаре
  (сегмент, размерная сетка, поставщики, сезонность) ведётся как первоклассное.
- **`sensitivity: private`.** Поставщики, закуп, наценка, клиентские данные — не
  для публики.
- **Секреты только указателями.** Соцсети/маркетплейс, рекламные кабинеты,
  реквизиты, контакты поставщиков — в `secrets/` / вне git; в vault только
  [[deeda/deeda-vault/secrets-map|secrets-map]].
- **Бизнес-знание — из плейбука.** Общие принципы стратегии/юнит-экономики брать
  из [[biz-knowledge/biz-knowledge-vault/HOME|biz-knowledge]], применяя к рознице
  (это единственный дозволенный источник кросс-знания; данные — свои).
- **Язык.** Инфраструктура — по базовому правилу; операционные заметки — на языке
  ведения дел.
