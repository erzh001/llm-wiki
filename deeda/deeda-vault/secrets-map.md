# secrets-map — deeda (указатели, без значений)

Где живут доступы домена. **Значения — только вне git** (`secrets/` / `.env` /
менеджер паролей). Здесь — карта, не секреты.

- **Соцсети / витрина** — Instagram / маркетплейс / сайт магазина → вне git.
- **Реклама** — рекламные кабинеты (таргет/контекст) → вне git.
- **Поставщики** — контакты, договоры, прайсы закупа → вне git.
- **Юрлицо / касса** — реквизиты, банк, ОФД/касса → вне git.
