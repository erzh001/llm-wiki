# ppu-manufacturing — производство труб ППУ (дверь)

Ты в `ppu-manufacturing/` — рабочий домен **физического производства**:
изготовление предизолированных труб ППУ (стальная труба + пенополиуретан +
ПЭ-оболочка) и смежная промышленная операционка (проект «teplocom»). Локальный
рынок — KZ. Рабочий домен, соседи `chem-resale/` / `expertise/` / `ppu/`;
создан из [[meta-vault/vault-template|vault-template]].

> ⚠️ **Три разных «ППУ»-домена, не путать:**
> - `chem-resale/` — **импорт** химкомпонентов (полиол/MDI) Китай→KZ (вход).
> - **`ppu-manufacturing/` (этот)** — **производство** трубы из этих компонентов.
> - `ppu/` — **разработка софта** ppu-crm (ERP/CRM), к производству отношения не имеет.
>
> Связь только одна и естественная: `chem-resale` поставляет сырьё, которое
> потребляет этот домен. Кросс-ссылку на chem-resale заводим (вход→производство).

Имя агенту уровня не присвоено (реестр имён: [[meta-vault/glossary|glossary]]).

Читать первым (мозг — это vault):
- `ppu-manufacturing-vault/status.md` — текущее состояние, читать каждую сессию.
- `ppu-manufacturing-vault/principles.md` — конвенции (база + дельты).
- `ppu-manufacturing-vault/HOME.md` — карта знания.
