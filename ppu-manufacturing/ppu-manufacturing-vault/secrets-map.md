# secrets-map — ppu-manufacturing (указатели, без значений)

Где живут доступы домена. **Значения — только вне git** (`secrets/` / `.env` /
менеджер паролей). Здесь — карта, не секреты.

- **ТОО (производство)** — реквизиты, ЭЦП, банк → вне git.
- **Поставщики** (газы — Востоктехгаз; энергия — Теплокомунэнерго) — договоры,
  лицевые счета → вне git.
- **«teplocom» (веб-приложение)** — доступы к приложению/хостингу → вне git.
