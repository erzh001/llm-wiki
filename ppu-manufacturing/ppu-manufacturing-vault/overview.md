# overview — что это за производство (сид из claude.ai + память)

> Первичный обзор из **тем чатов claude.ai** и памяти о производственной операции.
> Факты — гипотезы до подтверждения; углублять вытягиванием чатов.

## Суть

Физическое производство **предизолированной трубы ППУ**: стальная труба +
ППУ-изоляция (из полиола + MDI) + ПЭ-оболочка. Проект **«teplocom»** — учётное
веб-приложение под это производство. Действующая операция: цех, оборудование,
поставки сырья/энергии/газов, ТОО с партнёром.

## Место в цепочке

`chem-resale` (импорт полиол/MDI из Китая) → **ppu-manufacturing** (замес ППУ,
выпуск трубы) → сбыт трубы в KZ. Этот домен — потребитель сырья chem-resale.

## Что распознано (чаты + память)

- Чаты: Веб-приложение для производства труб ППУ (teplocom) · Расчёт стоимости
  изоляционных труб · Трещины на изоляции кабеля при монтаже · Программирование
  прокладки на ЧПУ Siemens · ИИ для контроля качества валов-шестерён · Проект
  производства развальцовочных приспособлений · Расчёт вентиляции цеха.
- Память: газы для производства (Востоктехгаз O₂/CO₂/пропан), компрессор
  BERG VK11P, коммунальные долги (Теплокомунэнерго), владелец — директор ТОО,
  **конфликт с партнёром (2026)**.

## Открытые вопросы

- Точный состав оборудования и производственная цепочка.
- Себестоимость трубы (сырьё + энергия + труд) и сбыт (покупатели, цены).
- Судьба ТОО на фоне партнёрского конфликта (чувствительное → private `life/`).
