# research — регуляторика ввоза (KZ / ЕАЭС)

> **TL;DR.** Первичная разведка кодов ТН ВЭД и экспортного контроля по
> компонентам ППУ. **Главный вывод: не «играть кодом» ради обхода контроля** —
> риск не в коде, а в связке *происхождение + назначение + документы*. Для BDMA
> корректный код — **2921 19 990 0** (или точнее ароматический **2921 49 000 9**).
> Внутри ЕАЭС (РФ→KZ) пошлины/растаможки нет — статформа.
>
> Источник — [[chem-resale/chem-resale-vault/sources/chatgpt-export-2026-07-27|ChatGPT-экспорт]].
> **Это ответы LLM, не консультация брокера.** Любой код перед сделкой
> подтверждать у таможенного брокера/декларанта — от кода зависят пошлина, НДС,
> сертификация и риск ареста груза.

## Коды ТН ВЭД (из разбора, требуют подтверждения)

| Товар | Код ТН ВЭД ЕАЭС | Примечание |
|---|---|---|
| BDMA / третичный амин | **2921 19 990 0** | прочие ациклические амины |
| BDMA (ароматич. кольцо) | **2921 49 000 9** | точнее по структуре (бензильная группа) |
| Якорь / часть ручного экструдера (пластик) | **8477 90 900 0** | части оборудования для переработки пластмасс; обычно 0% пошлина |
| Часть электродвигателя (якорь/статор/ротор) | **8503 00 98 00** | не «рисковый», досмотр не авто |
| Ручной сварочный экструдер (в сборе) | **8515 80 9000** | оборудование для сварки пластмасс |

Ошибка — прятать амин под **3824** («прочие химпродукты») или «смеси»: если в
COA написано Benzyl Dimethylamine, таможня переклассифицирует в 2921.

## Экспортный контроль

- BDMA **сам по себе не в типовых списках прекурсоров/ОМУ**, но может попасть
  под контроль по **двойному назначению** (списки, CAS-номенклатура). Контроль
  идёт **не по ТН ВЭД, а по назначению/CAS/спискам**.
- **Из РФ** — жёстче: ФСТЭК / Минпромторг, внутренние регламенты поставщика.
  **Из Китая / Турции** — обычно проще.
- **Снижение риска (правильный путь, не обход):**
  - Документы: **SDS (паспорт безопасности), COA (сертификат анализа), TDS**.
  - Письмо о назначении: *«катализатор для производства ППУ-изоляции труб»*.
  - Инвойс/контракт: *«Catalyst for polyurethane foam production (industrial use)»*.
  - У поставщика запросить: HS-code с их стороны + письмо *«не подпадает под
    экспортный контроль»*.
- **Изоцианаты (MDI)** — уточнить статус опасного груза (влияет на перевозчика,
  ADR, документы) — открытый вопрос по логистике (см. resale-pipeline, звено 3).

## Внутри ЕАЭС (РФ → Казахстан)

- **Таможенной пошлины и импортного оформления нет** — внутрисоюзная поставка,
  оформляется **статистическая форма** учёта перемещения товаров.
- Досмотр возможен при: новом поставщике, высокой стоимости, несоответствии
  описания, первой поставке по коду.

## Сопутствующие документы KZ

- **СНТ** — сопроводительная накладная на товары (виртуальный/электронный
  документооборот KZ). См. диалог в источнике.
- **ТТН** — товарно-транспортная накладная (напр. для газели по РК).
- **НДС** — расчёт при ввозе/реализации (разбор в источнике).
