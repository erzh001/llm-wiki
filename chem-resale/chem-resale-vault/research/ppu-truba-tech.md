# research — ППУ-труба и её компоненты (продуктовое знание)

> **TL;DR.** Товар канала — сырьё и компоненты для **предизолированной трубы
> ППУ** (district heating / НВК). Труба = 3 слоя: **стальная труба** (несущая) +
> **ПУ-пена** (изоляция) + **PE-оболочка** (защита). «Компонент Б» из vault =
> **изоцианат (полимерный MDI)**; мировой №1 и главный источник для СНГ —
> **Wanhua (Яньтай, CN)**. Катализатор ППУ-систем — **BDMA** (третичный амин),
> shelf-life 12–24 мес, деградирует от воздуха/влаги/тепла.
>
> Источник — [[chem-resale/chem-resale-vault/sources/chatgpt-export-2026-07-27|ChatGPT-экспорт]]
> (ответы LLM — сверять со спецификациями производителя перед сделкой).

## Конструкция ППУ-трубы (3 слоя)

1. **Стальная труба** — несёт давление и температуру. Марки: **сталь 20**,
   **09Г2С**.
2. **ПУ-пена (жёсткий ППУ)** — изоляция. Это и есть зона нашего сырья:
   полиол (компонент А) + изоцианат (компонент Б) + катализатор (BDMA).
3. **PE-оболочка (HDPE)** — наружная защита. PE80 / PE100.

Владелец работает по **НВК (водоснабжение)** и **теплоснабжению**, диаметры
**20–1020 мм**.

## Изоцианат (компонент Б)

- Для **жёсткого ППУ** (изоляция труб) — **MDI** (метилендифенилдиизоцианат).
  **TDI** — для мягких пен (мебель, матрасы), не наш профиль.
- **Крупнейшие производители:**
  - **Wanhua Chemical** (Яньтай, Нинбо; + BorsodChem, Венгрия) — **№1 в мире по
    MDI**, ключевой источник для СНГ.
  - BASF (Людвигсхафен, Антверпен, Шанхай), Covestro (Дормаген, Шанхай),
    Huntsman (Гейсмар, Роттердам, Шанхай), Dow.
  - В РФ MDI почти не производят (TDI — КуйбышевАзот/Тольятти,
    Нижнекамскнефтехим); MDI — импорт (Китай/Европа).
- Поставка: бочки / изотанки. Часто продаётся как **система «полиол А +
  изоцианат Б»**. Цена завязана на нефть, логистику, курс юаня/доллара.

## Катализатор — BDMA / DMEA

- **BDMA** (бензилдиметиламин) — третичный амин, катализатор ППУ. **DMEA**
  (диметилэтаноламин) — смежный.
- **Срок хранения:** 12–24 мес (в идеале до 2–3 лет). Производитель может
  **продлить срок сертификатом** (ретест партии, COA / extension letter) — это
  нормальная практика для аминов.
- **Деградация от:** воздуха (окисление → потемнение жёлтый→коричневый), влаги
  (меняет реакционную способность — критично для ПУ), тепла (опт. +10…+25 °C),
  УФ.
- **Входной контроль (без лаборатории):** цвет, запах, осадок/мутность + проба в
  реакции. С лабораторией — титрование аминов, GC. Правило склада: **FIFO**,
  маркировать дату вскрытия; после вскрытия использовать за 3–6 мес.
- Деградация катализатора «плывёт» время гелеобразования и структуру пены —
  для критичных партий тестовая варка обязательна.

## HDPE-оболочка — PE80 vs PE100

- **HDPE** — материал (полиэтилен высокой плотности); **PE80/PE100** — классы
  прочности. PE100 прочнее на ~20–25% → тоньше стенка при том же давлении.
- **Замена только PE80 → PE100** (в сторону улучшения); обратно нельзя.
- **Экономику считать по цене за метр при равном давлении**, не за тонну (PE100
  дороже за кг, но за счёт тоньше стенки часто выгоднее на 10–25%).
