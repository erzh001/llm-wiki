# Карта секретов — chem-resale

Только указатели, никогда значения (базовое правило).

Чувствительное этого домена (появится по мере сделок) держать **вне трекаемых
файлов** — в `secrets/` или локально, не в vault:

- Реквизиты поставщиков (Дензан, Дзинян, WChem), инвойсы, контракты.
- Банковские/каспи реквизиты для расчётов, платёжные данные.
- Логин/переписка с заводом и посредниками (почта, WeChat/мессенджеры).

В vault — только факт наличия и указатель, без содержимого.

Глобальная карта: [[meta-vault/secrets-map|meta-vault/secrets-map]].
