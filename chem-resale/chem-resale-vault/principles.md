# Принципы — chem-resale (дельты)

Следует **базе**: [[meta-vault/principles|meta-vault/principles]] +
[[meta-vault/vault-template|meta-vault/vault-template]]. Здесь — только дельты.

## Дельты

- **Независим от `ppu/`.** Несмотря на «ППУ» в названии товара, домен не связан
  с разработкой ppu-crm и с ppu-производством владельца (его решение). Общих
  сущностей, кросс-ссылок и «сам себе клиент» нет: это самостоятельная
  торговая единица.
- **`market/` = реальный рынок сбыта KZ.** Трактуем зону по канону-по-умолчанию
  (спрос, покупатели, цены в Казахстане), а не как продуктовый ландшафт.
  `competitors/` — другие импортёры/дистрибьюторы компонентов ППУ.
- **Клиентский бизнес.** `clients/` (покупатели KZ) и `positioning.md` (оффер) —
  активные зоны, не заглушки: сбыт — половина модели.
- **Поставщики и покупатели — в `people/`.** Один контрагент = одна карточка
  (канал, условия, инкотермс, история). Логист и таможенный брокер — тоже сюда.
- **`systems/` = схема бизнеса, не софт.** Главный «компонент» — pipeline сделки
  (сорсинг → импорт → таможня → склад → сбыт), а не приложение.
- **`sensitivity: private` по умолчанию.** Поставщики, закупочные цены, маржа,
  реквизиты — не для публики; репозиторий держать приватным.
- **Секреты только указателями.** Переписка с поставщиками, реквизиты, банк/
  каспи — в `secrets/` / вне git; в vault только
  [[chem-resale/chem-resale-vault/secrets-map|secrets-map]], без значений.
- **Язык.** Инфраструктура (дверь, принципы, README, решения) — по базовому
  правилу; операционные заметки — на языке, на котором владелец ведёт сделки.
