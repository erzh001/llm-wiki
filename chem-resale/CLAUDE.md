# chem-resale — импорт химкомпонентов ППУ (дверь)

Ты в `chem-resale/` — рабочий домен **импортно-торгового бизнеса**: закупка
компонентов для ППУ (пенополиуретан) в Китае, реализация в Казахстане. Схема —
сорсинг → импорт/таможня → склад → сбыт. Рабочий домен, соседи `study/` /
`creative/` / `ppu/`; создан из [[meta-vault/vault-template|vault-template]].

> ⚠️ **Не путать с `ppu/`.** Тот домен — разработка софта (ppu-crm). Этот —
> физическая перепродажа химии, **общего с ppu-производством не имеет** (решение
> владельца). Совпадение слова «ППУ» — только в названии товара, не в scope.
> Кросс-ссылок в `ppu/` не заводим.

Имя агенту уровня не присвоено (реестр имён: [[meta-vault/glossary|glossary]]).

Читать первым (мозг — это vault):
- `chem-resale-vault/status.md` — текущее состояние, читать каждую сессию.
- `chem-resale-vault/principles.md` — конвенции (база + дельты).
- `chem-resale-vault/HOME.md` — карта знания.

> **Инвариант (все уровни):** НИКОГДА не использовать `AskUserQuestion` /
> попап-диалоги с выбором — вопросы владельцу всегда обычным текстом.

## Стадия

**Сорсинг.** Выстраивается канал закупки: два поставщика в руках (Дензан;
перекупы в Дзиняне), официальный завод WChem — в исходящих (письмо не
отправлено). Сбыт в KZ пока не определён. Живые блокеры — в `status.md`.

## Внутри

- `chem-resale-vault/` — база знаний (см. HOME).
- Что за товар: двухкомпонентная система ППУ — компонент А (полиол) +
  компонент Б (изоцианат / полимерный MDI). Поставщики и покупатели — в
  `chem-resale-vault/people/`, схема сделки — `systems/resale-pipeline.md`.
- Доступы (переписка с поставщиками, реквизиты, каспи/банк) — только
  указателями в [[chem-resale/chem-resale-vault/secrets-map|secrets-map]];
  значения в `secrets/` / вне git.
